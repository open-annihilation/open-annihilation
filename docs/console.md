# The console

The chat line takes a command when the text starts with an ASCII `+`.
[Cheat codes](cheats.md) lists every code, what it does, and where it
works: every single-player game, and a multiplayer game's cheat codes
only when the battle room allows them.

A line that is not a command is chat. How to type a command when an
input method is composing another script is in [typing.md](typing.md).

`\` repeats the last command under the same rule as typing it again.
`+now Film Chris Include Reload Assert` turns developer mode on. That
opens the debug commands and the F11 debug keys. It does not allow cheat
codes when the game has them off.

`+stats` shows or hides the frame times over the battlefield, with the
graphics card each part of the picture is drawn on
([on a laptop](troubleshooting.md#a-slow-frame-rate-on-a-laptop)), and
saves the choice, as the performance setting does. `+stats 1` and `+stats 0`
show and hide them for this game without saving. It is an option: it
needs no passphrase and its echo stays on your machine.
