# Skirmish

The skirmish setup shows one row for each player place. A row reads
**Player**, **Computer** or **Open**. One row reads **Player**: that is
you. Clicking a **Computer** row makes it **Player** only when no row is
**Player**. Clicking the **Player** row makes it **Open**.

The rows stay as you left them, and so does the number of rows. A
campaign mission, a saved game, a recorded game and a network game seat
their own players for that match and put your rows back when you return
to the setup. Starting Open Annihilation again shows the same rows.

How many rows appear is **Skirmish players** under Settings › Engine
Limits, from 2 to 10. A new install shows all ten. A count you already
stored stays. The same count is what the setup's key codes `*III` to
`*X` set, and the slider shows the count a code stored. The row is
locked during a game.

A setup that names **Player** on two rows keeps **Player** on the last
of those rows, the row a skirmish starts as, and the earlier rows read
**Computer**, in the saved setup and again when it is loaded. A setup
with one **Player** is unchanged.

## Mutators

**Mutators** is one of the setup's own on and off buttons, between
**Difficulty** and **Previous Menu**, with the OA stamp at its left. It
reads **Mutators: off**, no lamp lit, while this skirmish will play none,
and **Mutators: 2 on**, its green lamp lit, while it will play two.
Resting the pointer on it, or the information key, shows a card that
lists them in the order they apply. The setup starts with mutators off.
It remembers the last set **START** handed on here, with its order and its
options. **Mutators** opens the picker on the set already chosen, or, when
nothing is chosen, on that remembered set. **USE THESE** makes it this
skirmish's set, and **START** plays it. **CANCEL** changes nothing. The
picker, the campaign launch and a battle room are
[Playing with mutators](playing-with-mutators.md).

## Brains

When a brain is installed, each **Computer** row's own Player button names
the seat's brain, **Computer** for the built-in player, and has a notch at
its right end. A click on the notch, or a right-click anywhere on the
button, opens the brain menu, drawn as the room's own list box under the
button: the built-in player, each installed brain with its level, **Use
for every computer seat**, **Options...** while the seat's brain has
options, and **Get more brains...**. A left-click elsewhere on the button
changes the row as 3.1c does. With no brain installed, the row is 3.1c's
own, and the built-in computer player plays the seat. The brain menu, a
campaign's computer player and a battle room are
[Playing with brains](playing-with-brains.md).
