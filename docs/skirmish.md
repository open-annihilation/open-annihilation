# Skirmish

The skirmish setup shows one row for each player place. A row reads
**Player**, **Computer** or **Open**. One row reads **Player**: that is
you. Clicking a **Computer** row makes it **Player** only when no row is
**Player**. Clicking the **Player** row makes it **Open**.

The rows stay as you left them, and so does the number of rows. A
campaign mission, a saved game, a recorded game and a network game seat
their own players for that match and put your rows back when you return
to the setup. Starting Open Annihilation again shows the same rows.

How many rows appear is **Skirmish players** under Settings › Engine
Limits, from 2 to 10. A new install shows all ten. A count you already
stored stays. The same count is what the setup's key codes `*III` to
`*X` set, and the slider shows the count a code stored. The row is
locked during a game.

A setup that names **Player** on two rows keeps **Player** on the last
of those rows, the row a skirmish starts as, and the earlier rows read
**Computer**, in the saved setup and again when it is loaded. A setup
with one **Player** is unchanged.

## Mutators

**Mutators** sits on the setup, between **Difficulty** and **Previous
Menu**, as large as **Previous Menu**, with the OA badge. It reads
**Mutators** while this skirmish will play none, and **Mutators (2)**
while it will play two; the picker shows which. The setup starts with
mutators off. It remembers the last set **START** handed on here, with
its order and its options. **Mutators** opens on the set already chosen,
or, when nothing is chosen, on that remembered set.
**USE THESE** makes it this skirmish's set, and **START** plays it.
**CANCEL** changes nothing. The picker, the campaign launch and a battle
room are [Playing with mutators](playing-with-mutators.md).

## Brains

When a brain is installed, each **Computer** row has a control to the
right of its Energy button. The control reads the seat's label, cut to
the space on the row: **Built-in** and the level, or the brain and its
level. It opens the picker titled **Computer player**. With no brain
installed, the row has no such control, and the built-in computer player
plays the seat. The picker, a campaign's computer player and a battle
room are [Playing with brains](playing-with-brains.md).
