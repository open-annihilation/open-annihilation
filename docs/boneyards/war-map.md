# The galactic map

After a login the game asks for the current war map. It keeps drawing
while it waits a few seconds. When the answer checks out, it replaces the
map kept in the player's Boneyards folder, and the galactic map is drawn
from that copy. When there is no answer in time, or the answer does not
check out, the map already on the machine is shown: the player's copy when
there is one, and otherwise the copy in the boneyards expansion, then a
copy in the game folder. The archive beside the program does not hold it.

## The Galactic day

The war's day turns at 02:00 in America/Los_Angeles, Pacific standard or
daylight time as that zone is on that date. Battles in the day that is
ending are what move the front. A day can also be advanced by hand from
the cluster's admin tools. The next 02:00 turn still comes after that.
Times stored and sent for the war stay UTC, apart from this turn.
