## Tools

- [CMake](https://cmake.org/): build system
- [LLVM and Clang](https://llvm.org/), [GCC](https://gcc.gnu.org/) and
  [mingw-w64](https://www.mingw-w64.org/): compilers, including the Windows
  builds ([llvm-mingw](https://github.com/mstorsjo/llvm-mingw) for Windows on
  ARM)
- [Python](https://www.python.org/): build and packaging scripts
- [Docker](https://www.docker.com/): Linux release builds
- [GitHub Actions](https://github.com/features/actions): continuous integration
- [Shields.io](https://shields.io/) and [Simple Icons](https://simpleicons.org/):
  README badges

The libraries included in the releases, such as SDL and zlib, and their
licences are listed in [ATTRIBUTIONS.md](ATTRIBUTIONS.md).
