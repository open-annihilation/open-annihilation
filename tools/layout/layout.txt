# The one-time layout pass: where every module, file, header, target and
# namespace of today's tree goes. tools/layout/layout.py reads this table;
# --check validates it against the tree, --apply performs it.
#
# One row per line: KIND OLD NEW SCOPE NOTE...; columns are separated by
# spaces, SCOPE is "-" when a row has none, and NOTE is the rest of the line
# (the reason for a judgement call). Blank lines and lines starting with #
# are ignored.
#
#   module     an old module directory and its new home. Its files follow
#              it; the headers under its include/ take their include rows.
#   file       one file moved on its own: out of a module that is split, or
#              renamed. It overrides the module row.
#   include    an old include path and its new one. A header of a module
#              moves to <new module>/include/<new include path>.
#   root       an old include root that is not a module's include/ (its
#              headers are named by file rows).
#   owner      the target that owns an old include directory (or a module
#              directory), for turning an include directory another module
#              reached into a link to it. It may name a target the pass
#              creates.
#   target     a library target and its new name; NEW - keeps it. Every
#              module library listed here gets ALIAS
#              oa::<group>::<module>[_part].
#   namespace  an old namespace and its new one; NEW = OLD keeps it. A
#              namespace nested in a renamed one follows it unless it has a
#              row of its own.
#   split      the names that the headers under SCOPE (old paths, comma
#              separated) declare in namespace OLD move to NEW, and so do
#              the declarations of OLD in files under SCOPE; the rest of
#              OLD follows its namespace row. Code that used a moved name
#              unqualified is given the new qualified name.
#   identifier an identifier renamed everywhere (code, comments, baselines);
#              SCOPE is the namespace or type that declares it.
#   docpath    an old directory that Markdown prose names, and the
#              directory it names after the pass (group directories that
#              are gone).
#   allow      a known dependency against the layer order (new target
#              names), written to tools/layout-baseline.json, which may
#              only shrink.
#   keep       an engine file (or directory) whose text the pass leaves as
#              it is, such as a test whose fixtures are made-up paths; its
#              post hunks still apply.
#
# By rule, and needing no row: a CMakeLists.txt loses the blocks that let
# its module build on its own and the sources that move to another module,
# with the targets they leave empty (the new modules' build files are in
# tools/layout/files/); files renamed within a module keep their names in
# its CMakeLists.txt; a module's project() takes the module's name
# (oa_<group>_<module>); hand-written edits are in tools/layout/patches.txt.
# A project's directory that --leave names stays as it is.
#
# Layer order (tools/check_layout.py): core, base, platform and formats,
# data, sim, present/audio/media, ui, app. A module's group is the first
# directory under src/.
