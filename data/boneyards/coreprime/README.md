# Core Prime data

Files in this directory are packed into `coreprime.ccx` at the same relative
path. This README is packed as `README.md`. GUI files for the new screens
live in `gui/` and are packed the same way.

The search radar, locator icons, queue meter and registration code are drawn
from the art sources into `anims/BY_New.gaf` when the archive is built. The
registration code is rendered from the build's registration address. The war
map is not packed into this archive.
